# STAR: Billing Workflow Automation (Factcil)

## Situation

Factcil, a Colombian Fintech helping freelancers who have to wait 30 to 90 days for payment, had a manual billing workflow that was inefficient and error-prone. The manual process limited the platform's ability to scale and created unnecessary friction for users.

## Task

Automate the entire billing workflow by introducing electronic invoicing, eliminating manual processes and enabling the platform to handle growing transaction volumes.

## Action

Designed and implemented an electronic invoicing system from scratch using Django, ReactJS, and AWS. Integrated it into the existing Fintech platform, ensuring compliance with Colombian financial regulations. Built the system to handle the full billing lifecycle without requiring manual intervention.

## Result

Achieved **100% automation efficiency** in the billing workflow, eliminating manual intervention entirely. The automation enabled the platform to scale its operations and serve more freelancers without increasing administrative overhead.
