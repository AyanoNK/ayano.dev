# STAR: Fraud Detection System (Verblio)

## Situation

Verblio's content platform had a significant problem with fraudulent accounts actively abusing the system. These accounts were impacting revenue, degrading platform quality, and undermining trust for legitimate users and content creators.

## Task

Design and implement a comprehensive fraud detection system to identify and eliminate fraudulent accounts from the platform.

## Action

Fully implemented a fraud detection system on the platform using Ruby on Rails. Built detection rules and automated enforcement mechanisms to identify fraudulent behavior patterns and take action on offending accounts. Integrated the system into the existing platform workflows to ensure seamless operation.

## Result

Reduced the number of active fraudulent accounts by **95%**, dramatically improving platform integrity and protecting revenue. The system operated automatically, requiring minimal manual oversight while maintaining a high detection rate.
