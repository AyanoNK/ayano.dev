# STAR: AI Agents for Oil & Gas Production (AWS Client)

## Situation

SoftServe was engaged by Amazon Web Services for a project requiring interpretation and prediction of oil and gas production data in the US. The critical challenge was that production data was trapped in PDF scans — unstructured documents that were difficult to analyze at scale. Traditional manual review was slow, error-prone, and couldn't support the predictive analytics the client needed.

## Task

Build and deploy AI Agents capable of extracting data from PDF scans, then interpreting, analyzing, and predicting oil and gas production trends — turning inaccessible documents into actionable insights.

## Action

Developed AI Agents leveraging the latest advancements in Generative AI and Large Language Models. Built PDF data extraction pipelines to parse unstructured scans into structured datasets. Designed interpretation and analysis layers that could identify production patterns, and implemented prediction models to forecast production trends. Deployed the full solution for the AWS client.

## Result

Achieved **70% accuracy** on tested cases for production predictions, enabling data-driven decision-making from previously inaccessible PDF documents. The solution transformed a manual, time-intensive process into an automated, AI-powered pipeline for the client.
