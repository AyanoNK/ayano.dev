### What I built

I designed and built a company-wide template for MCP servers, the servers that give AI agents access to tools and data. It includes authentication, authorization and common tooling out of the box, so a team starts from a working server that already has them.

### Results

- Every team now uses it as the standard whenever it creates a new MCP server.
- Setting up a new server went from about a week to one day.
