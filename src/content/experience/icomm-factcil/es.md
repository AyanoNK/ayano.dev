## El cliente y el problema

I-Comm construye productos SaaS a medida para clientes de los sectores fintech y de entrega de mercancías en Latinoamérica. Factcil, una startup fintech colombiana, era uno de esos clientes. Necesitaba software a medida para sus sistemas de facturación, pagos y finanzas.

## Lo que hice

Lideré el desarrollo y fui responsable de múltiples funcionalidades, usando Django para los servicios de backend, React para los frontends, AWS para la infraestructura en la nube y GitHub Actions para los pipelines de CI/CD. Participé en decisiones de arquitectura y diseño, configuré la infraestructura de despliegue, e implementé, probé y desplegué código de producción siguiendo la metodología Scrum.

- **Facturación electrónica.** Automaticé todo el flujo de facturación introduciendo la facturación electrónica, integrando los sistemas financieros y los flujos de cumplimiento normativo. El flujo alcanzó un 100% de automatización.
- **Suscripciones.** Fui pionero en las suscripciones y opciones de pago recurrente de la plataforma web de Factcil, usando integraciones de Stripe para el sistema de cobro recurrente.
- **Funcionalidades de la plataforma.** Implementé sistemas de pago, módulos de autenticación y métricas financieras para el producto.
- **Landing page.** Construí el 50% de la landing page anterior, usando React para los componentes y los mocks de Figma del diseñador para la entrega.

## Resultados

- El 100% del flujo de facturación automatizado con facturación electrónica.
- Suscripciones y pagos recurrentes disponibles en la plataforma por primera vez.
